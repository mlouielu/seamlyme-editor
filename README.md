# SeamlyMe Editor

A web-based body measurement editor for [Seamly2D](https://seamly.io/). Load a `.smis` file, enter measurements and formulas, and preview them on a live body figure.

**Live app:** https://mlouielu.github.io/seamlyme-editor/

## Development

```bash
cd app
npm install
npm run dev
```

## Build

```bash
cd app
npm run build   # output in app/dist/
```

The app is deployed to GitHub Pages with `VITE_BASE_URL=/seamlyme-editor/`.
